# tushlik-bot 🍽

Telegram-бот, который делит общий счёт за обед. Один платит за всех, бот считает, кто сколько должен, присылает каждому сумму и карту, напоминает и показывает, кто уже скинул.

*Telegram bot that splits a group lunch bill: one person pays, everyone picks what they ate, the bot sends each person their share and the payer's card, tracks receipts and reminds. Open source, MIT.*

## Как это работает

1. **Кто платил** один раз указывает карту (`/card`) и присылает боту в личку JSON с чеком.
2. Бот публикует счёт в общей группе. Под ним кнопка **«🍽 Отметить, что я ел»**: каждый в личке с ботом выбирает свои блюда кнопками (ничего не пишет).
3. Платил нажимает **«Закрыть счёт»**. Бот тегает каждого в группе с суммой, а в личку присылает сумму и карту.
4. Каждый присылает чек (фото или файл) или жмёт **«Я оплатил»**, а может **отложить** — тогда придёт напоминание. Платил видит все ответы и подтверждает, что деньги пришли.
5. Платил видит, кто ещё не скинул, и может **пингануть** — тому придёт напоминание в личку.

Как считается доля:
- блюдо платят те, кто его выбрал, по числу порций (одну пиццу на троих делят на троих);
- общее (`shared`: чай, хлеб) делится поровну на всех участников;
- обслуживание (`service_percent`) добавляется к доле каждого;
- каждая сумма округляется вверх до `ROUND_TO` (по умолчанию 100), чтобы платил не терял на округлении;
- то, что никто не выбрал, остаётся на том, кто платил (бот предупредит перед закрытием).

## Формат счёта

```json
{
  "title": "Обед в Рохат",
  "items": [
    {"name": "Плов", "price": 45000, "qty": 3},
    {"name": "Лагман", "price": 38000}
  ],
  "shared": [
    {"name": "Чай", "price": 12000},
    {"name": "Хлеб", "price": 4000, "qty": 2}
  ],
  "service_percent": 15,
  "total": 221950
}
```

`price` — цена одной порции, `qty` — число порций (по умолчанию 1), `total` — итог по чеку (необязателен, нужен для сверки). Удобно попросить ИИ: «сделай JSON по фото этого чека в формате tushlik-bot».

## Донаты

- **🖥 На сервер** — месячная цель: `SERVER_COST_USD` + `SERVER_TAX_PERCENT` (по умолчанию $10 + 12%), пересчитанная в сумы по `USD_RATE`. В меню видна полоска прогресса.
- **☕ Купить кофе** — просто спасибо автору.

Донатер пишет сумму, переводит на карту автора и жмёт «Я отправил» (можно с чеком). Автор подтверждает или отменяет, донатер получает ответ. Лидерборд донатов — за месяц и за всё время. Если к концу месяца на сервер не собралось, остаток записывается на автора и тоже виден в лидерборде. Предложение поддержать бота приходит после того, как человек рассчитался, и тому, кто платил, когда все скинули.

## Запуск

```bash
cp .env.example .env   # заполни BOT_TOKEN, POSTGRES_PASSWORD, OWNER_ID, OWNER_CARD
docker compose up -d --build
docker compose logs -f bot
```

Бот работает через long polling: открытые порты и домен не нужны. Postgres свой, в том же compose.

Разработка:

```bash
pip install -r requirements-dev.txt
ruff check bot tests && pytest -q
```
