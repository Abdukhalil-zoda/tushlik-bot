# Как помочь проекту

Любые идеи приветствуются: открой issue или пришли pull request.

1. Сделай форк, создай ветку.
2. Запусти тесты: `pip install -r requirements-dev.txt && ruff check bot tests && pytest -q`.
3. Опиши в PR, что изменилось для людей в чате (лучше со скриншотом).

Правила:
- Деньги считаются только в `bot/split.py`; любое изменение формулы требует теста в `tests/test_split.py`.
- Тексты и кнопки — в `bot/ui.py`, SQL — только в `bot/db.py`, схема БД — новым файлом `migrations/00N_*.sql` (старые не меняй).
- Не коммить `.env`, токены и номера карт.
